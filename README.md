# 無脊椎動物なかま分け（musekitsui-nakama）

背骨のない動物（トンボ・ダンゴムシ・ジョロウグモ・ムカデ・タコ など）のからだのつくりを見て、なかま（昆虫類・甲殻類・クモ類・多足類・軟体動物）を当てる1日5問の学習ゲーム。正解したら「あしは？」も選ぶ。中学理科「動物のなかま」。

遊ぶ: <https://satou-aaaaa.github.io/musekitsui-nakama/>

- 中身は大阪府教育委員会の確認プリント（解答）、岩手県立博物館「けんぱくものしりシート」、京都大学白浜水族館「節足動物」、兵庫県立人と自然の博物館「ハーモニー」、お茶の水女子大学湾岸生物教育研究センター「海洋生物」で確かめたことだけです。
- 背骨のある動物は扱いません（動物なかま分けで扱います）。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
